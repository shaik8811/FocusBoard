# AI Usage Disclosure — FocusBoard

## Tools used
ChatGPT (OpenAI) assisted with planning, implementation, debugging, styling, accessibility and documentation.

## Representative prompts (paraphrased from the development conversation)
1. “Build my FocusBoard React project step by step.”
2. “Where should I place the useEffect that saves tasks in localStorage?”
3. “Why does the dashboard show Stats is not defined?”
4. “Help verify everything in the FocusBoard assessment is complete.”
5. “Complete the remaining requirements and prepare a deployable project.”

## AI-assisted areas
React component design, task CRUD and filters, carousel state, CSS responsiveness, validation, documentation and deployment instructions.

## Example of a suggestion reviewed and corrected
The initial edit flow only prompted for a new task title. The assignment required task editing, so this was revised into a full form that edits title, description, category, status, priority and due date. The earlier form also omitted status and Cancel controls, which were added after reviewing the assessment.

## Human review
The developer should test the build and browser interactions, verify the live Figma styling, review the generated code, and be ready to explain and modify it during evaluation. AI assistance does not replace these checks.
